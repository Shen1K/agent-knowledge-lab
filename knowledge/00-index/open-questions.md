# Open Questions

- What is the minimum knowledge claim schema that remains useful without becoming heavy?
- How much evidence is enough to upgrade a claim from `hypothesis` to `validated`?
- How should an agent attribute a bad output to a specific missing or wrong knowledge unit?
- Which relationships should stay explicit, and which should be inferred by tools?
- How should general knowledge and project-specific knowledge be separated?
