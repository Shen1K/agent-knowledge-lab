# Example: GitHub Issue Triage

This example shows how the knowledge system can be used for a domain with cheap continuous input and visible feedback.

## Task

Help an agent triage GitHub issues.

Potential outputs:

- issue type
- labels
- duplicate candidates
- missing information
- maintainer reply draft
- confidence and cited knowledge

Feedback signals:

- labels accepted or changed
- maintainer reply adopted or rewritten
- user provides missing information
- issue is closed as duplicate
- issue is resolved faster
